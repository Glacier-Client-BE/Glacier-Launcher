### 5.12 `frontend/src/interop.js` (522 lines) — faithful port
Diffed line-for-line against the original. Only intentional changes:
- 1–20: WebView2 `postToHost` → `@tauri-apps/api/window` (`startDragging`, `close`,

- 40–65 removed: `glacierRegisterDropHandler` and the `chrome.webview` message listener,
